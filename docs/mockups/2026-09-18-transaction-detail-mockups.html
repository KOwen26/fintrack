Transaction Detail · Mockup Explorations

Three explorations for the transaction detail page — each handles a regular transaction (expense / income) and a transfer (source → destination). Mobile-first, responsive up to desktop. Theme: Cobalt, tokens verbatim from resources/css/colors.css. Toggle any variant between states.

A

Ledger / Receipt — editorial

Freestyle exploration. Treats the transaction as a printed document: serif merchant name (Arvo), oversized tabular numerals, receipt rows with hairline rules and a mono micro-footer with a status stamp. Desktop adds an icon rail and a "journal" column — note, activity timeline, creator — beside the paper.

B

Bento Modern — composed grid

Freestyle exploration. The page becomes a composed set of tiles: a tonal hero washed with the flow color, a dedicated flow tile for transfers (source → destination with a linked-entry note), paired category / notes / meta tiles. Desktop arranges them in an asymmetric bento grid; narrow containers collapse to a single quiet column.

C

Design System — faithful

Ported 1:1 from the app's real components: ResponsiveCard (edge-to-edge with hairlines on mobile, bordered + rounded on desktop), soft Badge, mono 48px amount, accent bar, AccountInfo / CategoryInfo chips, DaisyUI cobalt radii (4px fields, 8px boxes). Includes the approved transfer upgrade — distinct From → To accounts with a linked-entry advisory — plus the real accent-bar quirk (warning bar, info amount) preserved on purpose.
