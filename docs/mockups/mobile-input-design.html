Mobile Input Design

Nine input patterns and five textarea patterns used across mobile apps — each in its meaningful states, rendered with the Tegas Senja tokens. Tap around: focus, error, and interactive behaviors are live.

01 · Filled Floating Label

Material filled

Soft gray field that lifts into a white bordered box on focus. The friendliest default for dense forms — Google apps, Grab, Gojek. Label doubles as placeholder, so rows stay short.

02 · Outlined Floating Label

Material outlined

The workhorse bordered field. Reads more "form-like" than filled — better when fields sit on white cards, since the border defines the target without needing gray fill.

Default
Filled

03 · Underline Minimal

Classic Material / print forms

No box at all — just a caption and a rule. The quietest option; ideal for long settings-style forms where boxes would feel heavy. Weakest affordance for touch targets.

Default
Filled

04 · Grouped List Rows

iOS Settings

The input disappears into a settings list — label left, value right. Best when fields are short and the form is really a detail sheet. Zero per-field chrome; the card is the field.

07 · Search Pill

Every list app

A field that pretends not to be a form: pill-shaped, icon-led, chromatically quiet until focused. Use for filtering, not for data entry.

08 · Segmented OTP

Auth / verification

One digit per box, auto-advancing. Fields split into segments read as "code", not "essay" — the same segmentation trick also works for fixed-format data.

Type — it auto-advances and fills

Quantity pickers

When the value is a small bounded number, buttons beat typing. Pairs naturally with an adorned field for "price × qty" capture.
